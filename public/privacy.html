Math For Dummy 개인정보처리방침

최종 수정일: 2026년 9월 18일

Math For Dummy(이하 "서비스")는 사용자의 개인정보를 소중히 여기며, 개인정보보호법 및 관련 법령을 준수합니다. 본 서비스는 개인 서버 없이 동작하는 클라이언트 사이드 웹 애플리케이션(SPA)입니다.

1. 수집하는 개인정보 항목

본 서비스는 개인 서버 없이 동작하며, 사용자의 동기화 선택에 따라 다음과 같은 정보가 처리됩니다.

  • Supabase 웹 클라우드 계정 정보: 사용자가 웹 클라우드 동기화를 이용할 경우, 로그인용 이메일 및 비밀번호(Supabase Auth 암호화 해시 보관)가 처리되며, 본인의 학습 진도 데이터(`user_progress`)가 안전하게 보관됩니다.
  • Google 계정 인증 정보: Google 로그인 선택 시 사용자의 이름, 이메일, 프로필 사진 URL이 클라이언트 브라우저 세션에만 임시로 표시됩니다.
  • 학습 데이터: 사용자가 학습한 수학 플래시카드 진도, 점수, 복습 간격 데이터는 오직 사용자의 로컬 브라우저(IndexedDB), 또는 사용자가 설정한 Supabase / Google Drive / GitHub 클라우드에만 보관됩니다.

2. 사용자 데이터 사용 및 접근 권한

  • Supabase 클라우드: Row Level Security (RLS) 정책에 따라 오직 로그인된 본인 계정의 데이터만 조회 및 수정할 수 있습니다.
  • Google Drive API: 오직 본 서비스가 생성한 학습 진도 파일(math_for_dummy_data.json)을 사용자의 개인 Google Drive 전용 앱 폴더(`appDataFolder`)에 저장하고 불러오는 목적으로만 사용되며, 다른 파일에 접근하지 않습니다.
  • 수집된 모든 데이터는 제3자에게 판매되거나 마케팅 목적으로 활용되지 않습니다.

3. 개인정보의 보관 및 파기

  • 사용자는 언제든지 서비스 내 [설정] 메뉴에서 [로그아웃] 또는 [연동 해제] 버튼을 눌러 계정 연결을 해제할 수 있습니다.
  • 로컬에 저장된 학습 데이터는 브라우저 캐시 삭제 또는 설정 메뉴를 통해 언제든지 즉시 삭제할 수 있습니다.

4. 문의처

서비스 이용 또는 개인정보 보호와 관련된 문의사항은 GitHub 리포지토리 Issue 또는 개발자 문의를 이용해 주시기 바랍니다.
